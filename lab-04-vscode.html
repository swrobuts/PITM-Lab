Visual Studio Code

Colab braucht keine Installation, dafür gehört der Rechner Google. Ein Editor auf dem eigenen Gerät kehrt das um: Alles liegt bei Ihnen, dafür müssen Sie es einrichten. Der Aufwand besteht im Wesentlichen aus einer Entscheidung, die neunzig Prozent aller Anfängerprobleme erklärt – nämlich welches Python gerade rechnet. Dieses Lab dreht sich um diese eine Frage und um die Handgriffe, mit denen sie sich jederzeit beantworten lässt. Colab needs no installation, but the machine belongs to Google. An editor on your own device reverses that: everything is yours, but you have to set it up. The effort essentially consists of one decision that explains ninety percent of all beginners' problems – namely which Python is computing right now. This lab revolves around that one question and the actions that answer it at any moment.

Ein Editor, der zur Umgebung wirdAn editor that becomes an environment

Visual Studio Code ist im Kern ein Texteditor. Alles, was ihn zur Entwicklungsumgebung macht – Python-Unterstützung, Fehlersuche, Notebook-Ansicht, Datenbankzugriff –, kommt über Erweiterungen hinzu. Das erklärt beides: warum er so klein startet und warum zwei Installationen völlig verschieden aussehen können. Visual Studio Code is at heart a text editor. Everything that makes it a development environment – Python support, debugging, notebook view, database access – is added through extensions. That explains both: why it starts so small and why two installations can look completely different.

Zwei Lizenzen, ein ProgrammTwo licences, one program

Der Quellcode steht unter der MIT-Lizenz auf GitHub. Das Programm, das man von code.visualstudio.com herunterlädt, ist etwas anderes: Microsofts eigener Bau, unter Microsofts Lizenzbedingungen, mit Telemetrie und Markenzeichen. Beides ist kostenlos, aber nur eines ist Open Source. Wer die freie Fassung will, nimmt VSCodium – derselbe Quellcode, MIT-lizenziert gebaut, ohne Telemetrie; der Preis ist ein kleinerer Erweiterungskatalog, weil der Microsoft-Marktplatz laut seinen Bedingungen nur mit Microsofts Programmen genutzt werden darf. The source code is on GitHub under the MIT licence. The program you download from code.visualstudio.com is something else: Microsoft's own build, under Microsoft's licence terms, with telemetry and trademarks. Both are free of charge, but only one is open source. Whoever wants the free version takes VSCodium – the same source, built under MIT, without telemetry; the price is a smaller extension catalogue, because the Microsoft marketplace may, by its terms, only be used with Microsoft's products.

InbetriebnahmeSetting it up

Drei Dinge werden gebraucht, und nur eines davon ist der Editor: Python, Git und VS Code. Python kommt nicht mit dem Editor – das ist die erste Überraschung für alle, die von Colab kommen. Three things are needed, and only one of them is the editor: Python, Git and VS Code. Python does not come with the editor – that is the first surprise for anyone arriving from Colab.

Danach zwei Erweiterungen, mehr nicht: Python (ms-python.python, bringt Pylance und den Debugger mit) und Jupyter (ms-toolsai.jupyter). Alles Weitere kommt, wenn es gebraucht wird – dazu unten der Abschnitt über Erweiterungen. Then two extensions, no more: Python (ms-python.python, bringing Pylance and the debugger with it) and Jupyter (ms-toolsai.jupyter). Everything else comes when it is needed – see the section on extensions below.

Ordner, nicht DateiFolder, not file

Der häufigste Bedienfehler des ersten Tages: eine Datei im Dateimanager doppelklicken. VS Code öffnet sie – und weiß nichts über das Projekt drumherum. Kein Dateibaum, keine Umgebungserkennung, keine Git-Ansicht, und relative Pfade im Code beziehen sich auf etwas Unerwartetes. The most common operating error of day one: double-clicking a file in the file manager. VS Code opens it – and knows nothing about the project around it. No file tree, no environment detection, no Git view, and relative paths in the code refer to something unexpected.

Die RegelThe rule

Immer den Projektordner öffnen, nie eine einzelne Datei. Aus der Konsole geht das mit code . – der Punkt ist wieder das aktuelle Verzeichnis, wie in Lab 01. Der Ordner ist gleichzeitig der Bezugspunkt für alles andere: das Repository, die virtuelle Umgebung, die relativen Pfade und die projektbezogenen Einstellungen. Always open the project folder, never a single file. From the console that is code . – the dot is again the current directory, as in lab 01. The folder is at the same time the point of reference for everything else: the repository, the virtual environment, the relative paths and the project-specific settings.

Ein Blick in die Statusleiste unten sagt danach jederzeit, wo Sie stehen: links der Git-Zweig, rechts der gewählte Python-Interpreter, das Zeilenende (LF oder CRLF) und die Zeichenkodierung. Vier Angaben, die zusammen die meisten Rätsel des Tages auflösen. A glance at the status bar at the bottom then tells you at any moment where you stand: on the left the Git branch, on the right the selected Python interpreter, the line ending (LF or CRLF) and the character encoding. Four pieces of information that together resolve most of the day's puzzles.

Die eigene UmgebungA project's own environment

Eine virtuelle Umgebung ist ein Ordner im Projekt, der eine eigene Python-Installation samt eigenen Paketen enthält. Das klingt nach Umstand und ist eine der besten Angewohnheiten überhaupt: Projekt A braucht pandas 2.2, Projekt B braucht pandas 1.5, und ohne getrennte Umgebungen schließen sich die beiden gegenseitig aus. A virtual environment is a folder in the project holding its own Python installation with its own packages. That sounds like a nuisance and is one of the best habits there is: project A needs pandas 2.2, project B needs pandas 1.5, and without separate environments the two exclude each other.

Der Ordner .venv gehört nicht ins Repository – er ist plattformabhängig und mehrere Hundert Megabyte groß. Was hineingehört, ist die Liste der Pakete: pip freeze > requirements.txt. Damit stellt jemand anderes dieselbe Umgebung mit pip install -r requirements.txt her. In Lab 03 stand .venv/ deshalb in der .gitignore – hier sehen Sie, warum. The .venv folder does not belong in the repository – it is platform-dependent and several hundred megabytes in size. What does belong there is the list of packages: pip freeze > requirements.txt. With it, somebody else recreates the same environment using pip install -r requirements.txt. In lab 03 .venv/ was in the .gitignore for that reason – here you see why.

ModuleNotFoundErrorModuleNotFoundError

Die häufigste Fehlermeldung des Semesters, und fast immer dieselbe Ursache: pip hat in eine Umgebung installiert und der Editor rechnet in einer anderen. Die Meldung lautet dann sinngemäß „das Paket, das ich gerade installiert habe, gibt es nicht“ – und genau das stimmt auch, aus Sicht des Interpreters. The most common error message of the semester, and almost always the same cause: pip installed into one environment and the editor is computing in another. The message then effectively reads “the package I just installed does not exist” – and that is exactly right, from the interpreter's point of view.

Die Diagnose in drei ZeilenThe diagnosis in three lines

python -c "import sys; print(sys.executable)" ← welches Python rechnet gerade? pip -V ← wohin installiert pip? Beide Pfade müssen auf .venv zeigen.

Zeigen die zwei Pfade auf verschiedene Orte, ist die Ursache gefunden. Drei Gegenmittel, in dieser Reihenfolge: den Interpreter in der Statusleiste auf .venv stellen; das Terminal schließen und neu öffnen, damit es die Umgebung übernimmt; im Zweifel python -m pip install … statt pip install … verwenden – so installiert genau das Python, das gerade läuft. If the two paths point to different places, the cause is found. Three remedies, in this order: set the interpreter in the status bar to .venv; close the terminal and reopen it so it picks up the environment; when in doubt use python -m pip install … instead of pip install … – that way exactly the Python currently running does the installing.

Der Prompt im Terminal ist dabei der schnellste Hinweis: Steht dort (.venv) am Anfang der Zeile, ist die Umgebung aktiv. Fehlt es, ist sie es nicht – ganz gleich, was der Editor oben anzeigt. The terminal prompt is the fastest clue: if (.venv) stands at the start of the line, the environment is active. If it is missing, it is not – regardless of what the editor displays at the top.

Die vierzehn HandgriffeThe fourteen actions

Ein einziger davon macht alle anderen entbehrlich: die Befehlspalette. Sie findet jeden Befehl über seinen Namen, sodass man keine Menüs durchsuchen und keine Tastenkürzel lernen muss. One of them makes all the others dispensable: the command palette. It finds every command by name, so there are no menus to search and no shortcuts to learn.

Notebooks im EditorNotebooks in the editor

Eine .ipynb-Datei öffnet VS Code als Notebook, mit Zellen und Ausgaben wie in Colab. Es gibt aber einen zusätzlichen Begriff, der in Colab fehlt, weil es dort nur eine Umgebung gibt: den Kernel. Oben rechts steht, welcher gewählt ist – und der muss auf .venv zeigen, sonst gilt derselbe ModuleNotFoundError wie oben, nur an anderer Stelle. VS Code opens an .ipynb file as a notebook, with cells and outputs as in Colab. There is one additional concept, though, absent in Colab because there is only one environment there: the kernel. The top right says which one is selected – and it has to point to .venv, otherwise the same ModuleNotFoundError as above applies, just in a different place.

Erweiterungen und VertrauenExtensions and trust

Erweiterungen laufen ohne Sandbox mit Ihren Benutzerrechten. Eine Erweiterung kann jede Datei lesen, die Sie lesen können, und ins Netz senden, was sie will. Das ist kein theoretisches Risiko: 2025 und 2026 wurden im Marktplatz Erweiterungen mit gültigen Zugangsschlüsseln gefunden, und ein übernommenes Veröffentlichungs-Token erlaubt es, Schadcode über die automatische Aktualisierung auszuliefern. Extensions run without a sandbox with your user rights. An extension can read every file you can read and send whatever it wants to the network. That is not a theoretical risk: in 2025 and 2026 extensions with valid access keys were found in the marketplace, and a compromised publisher token allows malicious code to be delivered through the automatic update.

Wenige, geprüfteFew, checked

Herausgeber, Installationszahl und Verweis auf das Quell-Repository prüfen. Namensdubletten sind dokumentiert – der Name allein ist kein Beleg. Für diesen Kurs genügen Python und Jupyter. Check the publisher, the install count and the link to the source repository. Name duplicates are documented – the name alone is no proof. For this course Python and Jupyter are enough.

Workspace Trust

Beim Öffnen eines fremden Ordners fragt VS Code, ob Sie ihm vertrauen. Im eingeschränkten Modus sind Terminal, Aufgaben, Debugger und KI-Agenten abgeschaltet. Bei einem geklonten Übungsrepository lohnt es, den Modus zunächst zu behalten und erst nach einem Blick in die Dateien freizugeben. When opening an unfamiliar folder VS Code asks whether you trust it. In restricted mode terminal, tasks, debugger and AI agents are switched off. With a cloned exercise repository it is worth keeping the mode at first and only releasing it after a look at the files.

Telemetrie

Microsoft erhebt Nutzungsdaten; die Lizenzbedingungen fassen die Nutzung als Einwilligung. Abschalten mit "telemetry.telemetryLevel": "off". Wichtig: Das gilt nicht für Erweiterungen – die regeln ihre Datenerhebung selbst. Microsoft collects usage data; the licence terms treat use as consent. Switch it off with "telemetry.telemetryLevel": "off". Important: that does not cover extensions – they govern their own data collection.

Settings Sync

Synchronisiert Einstellungen, Tastenkürzel und Erweiterungen über ein Microsoft- oder GitHub-Konto. Bequem – und ein Grund mehr, keine Zugangsdaten in settings.json zu schreiben: Die Datei wird mitsynchronisiert. Synchronises settings, keybindings and extensions through a Microsoft or GitHub account. Convenient – and one more reason to write no credentials into settings.json: the file is synchronised along.

KI-AssistenzAI assistance

GitHub Copilot ist über GitHub Education für Studierende kostenfrei und überträgt Code-Kontext an GitHub und Microsoft. Bei Übungsdaten ohne Personenbezug ist das unkritisch. Bei einer Abschlussarbeit mit Unternehmensdaten ist es eine Verarbeitung, die geklärt sein muss – dieselbe Frage wie in Lab 02. GitHub Copilot is free for students via GitHub Education and transmits code context to GitHub and Microsoft. With exercise data free of personal reference that is harmless. In a thesis with company data it is a processing operation that has to be cleared – the same question as in lab 02.

ZeilenendenLine endings

Windows beendet Zeilen mit CRLF, macOS und Linux mit LF. In einer Gruppe mit gemischten Systemen meldet Git dann ganze Dateien als geändert, obwohl niemand etwas getippt hat. Gegenmittel: "files.eol": "\n" und eine .gitattributes im Repository. Windows ends lines with CRLF, macOS and Linux with LF. In a group with mixed systems Git then reports whole files as changed although nobody typed anything. Remedy: "files.eol": "\n" and a .gitattributes in the repository.

You work through the first two on your own machine – for those you need VS Code installed. The other three test whether the diagnosis has taken hold.
